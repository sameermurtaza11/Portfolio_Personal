# Sameer Murtaza — Portfolio

Personal portfolio website: https://sameermurtaza11.github.io/Portfolio_Personal/

Static site (HTML, CSS, vanilla JS) — no build step. Open `index.html` or serve the folder with any static server.

```
index.html        page markup
css/style.css     styles (dark theme, responsive)
js/main.js        typing effect, mobile nav, scroll animations, contact form
assets/           favicon and images (SVG)
```

Edit the contact email, links and text directly in `index.html` / `js/main.js`.
